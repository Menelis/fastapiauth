# FastAPI Auth & Book Management Service

A production-ready asynchronous RESTful API built with [FastAPI](https://fastapi.tiangolo.com/), [SQLAlchemy 2.0 (Async)](https://www.sqlalchemy.org/), [Alembic](https://alembic.sqlalchemy.org/), and **PostgreSQL**. Features full JWT-based authentication (access tokens, password hashing, route protection) alongside CRUD endpoints for user and book management.

---

## 🛠 Tech Stack

* **Framework:** [FastAPI](https://fastapi.tiangolo.com/)
* **Database:** PostgreSQL
* **ORM:** [SQLAlchemy 2.0](https://www.sqlalchemy.org/) (Async Engine)
* **Database Driver:** `asyncpg`
* **Migrations:** [Alembic](https://alembic.sqlalchemy.org/)
* **Authentication:** Passlib (Bcrypt) & PyJWT
* **Package/Environment Manager:** [uv](https://github.com/astral-sh/uv) or `pip`
